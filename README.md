## ONE TEXTBOOK A DAY!

> I have been thinking of feeding my brain a little math everyday. Also, I am a bit too clumsy towards which one to consider.
> So I made a tool with *Python* that could randomly pick me a book.
******************************************************************************
#### How to use it?
* Make sure you have *Python* installed.
* In the Terminal, move to directory to where it is saved.
* Run `python math.pick.py`.
*It will output a book's name by randomly selecting one from the list.*
* Also, make sure you delete the book's name you've completed reading from the list; saves overcrowding.
